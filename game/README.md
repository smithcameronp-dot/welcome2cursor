# Game

Planning folder for a new browser game in this repo. Nothing here is built yet.

## How we use this folder

`PLAN.md` is the working document. We lock decisions there before writing game code. When a section is still open, it stays marked open. When we agree, we replace the proposal with the decision.

Code will live in this same folder once we start building, so the game can be cloned and reset on its own.
